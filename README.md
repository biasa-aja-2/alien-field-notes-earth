One line, 1 to 200 characters: a review of planet Earth left by an alien tourist after a two-day visit. The tourist reports, baffled, that Earthlings wave their groceries at a beeping box, pay the box, then bag it themselves — and still awards five stars.

> Two-day trip report: the locals wave their groceries at a beeping box, pay the box, then bag it themselves. Five stars; would orbit again.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–200 characters, one line, not whitespace-only) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
